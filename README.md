# イコラブ コール練習

＝LOVE（イコラブ）のコールを、ライブ映像の再生位置に合わせて表示する個人用の練習ツールです。

- コールとタイムスタンプは [＝LOVE（イコラブ） コール一覧・ライブガイド](https://ikorabucall.com/)（非公式ファンサイト）の各曲ページを、開くたびに WordPress REST API から読み込んで表示します。
- このリポジトリにはコールのデータも歌詞も含まれていません。
- 映像は各曲ページに埋め込まれているライブ映像を YouTube IFrame Player API で再生します。

## 使い方

GitHub Pages で開きます：https://waiyangar572.github.io/ikorabu-call-trainer/

曲を選んで再生すると、今のコールが大きく、次のコールがカウントダウン付きで表示されます。ズレ補正、0.75倍・0.5倍速、練習モード（コールを伏せる）があります。
